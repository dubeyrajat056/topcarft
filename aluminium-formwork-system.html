Overview

RCC Buildings, Poured with Precision

Aluminium formwork is a construction system for forming cast-in-place concrete structures. TopCraft's system provides formwork for RCC load-bearing multi-storeyed buildings and enables walls and slabs to be poured in the same operation.

This increases efficiency and produces an extraordinarily strong structure with an excellent concrete finish — reducing plastering and rework.

  • 200+ reuses per set
  • 4–7 day slab-to-slab cycle
  • Minimal or no internal plastering
  • Manual assembly — no heavy cranes
